# RecipeXMLApp

**RecipeXMLApp** — учебное Android-приложение с рецептами, разработанное на языке **Kotlin** с использованием классической XML-вёрстки.  
Проект создан для изучения Android-разработки, работы с фрагментами, списками, моделями данных и навигацией между экранами.

---

## 📱 Основные возможности

- Просмотр категорий блюд
- Отображение названия, описания и изображения категории
- Просмотр списка рецептов выбранной категории
- Переход на экран выбранного рецепта
- Отдельный экран для избранных рецептов
- Навигация между категориями и избранным
- Передача данных между экранами
- Загрузка изображений из локальных ресурсов приложения

Сейчас данные хранятся непосредственно в приложении с помощью временного репозитория-заглушки `STUB`.

---

## 🧩 Основные экраны

### Категории

Главный экран приложения со списком категорий блюд:

- бургеры;
- десерты;
- пицца;
- рыба;
- супы;
- салаты.

### Рецепты

После выбора категории открывается список доступных рецептов с названиями и изображениями.

На текущем этапе реализован список рецептов для категории **«Бургеры»**.

### Детальный экран

При выборе рецепта открывается отдельный экран с информацией о выбранном блюде.

### Избранное

Отдельный экран для рецептов, добавленных пользователем в избранное.  
Функциональность сохранения избранных рецептов находится в разработке.

## 🧠 Что реализовано в проекте

- Single-Activity подход
- Работа с `Activity` и `Fragment`
- Навигация между фрагментами
- Использование `RecyclerView`
- Создание собственных адаптеров
- Обработка нажатий на элементы списка
- Передача данных через `Bundle`
- Использование `Parcelable`
- Работа с `ViewBinding`
- Модели данных `Category`, `Recipe` и `Ingredient`
- Репозиторий-заглушка с тестовыми данными
- XML-вёрстка пользовательского интерфейса
